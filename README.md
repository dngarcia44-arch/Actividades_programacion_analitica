# Actividades_programacion_analitica

## Descripción

En este repositorio se encuentran los proyectos y actividades desarrollados durante la clase de **Programación de Analítica de Datos**.

El objetivo del repositorio es almacenar y organizar los ejercicios realizados durante el curso, aplicando conceptos de programación orientados al análisis y manejo de datos.

## Contenido

En las diferentes carpetas se almacenarán las actividades y proyectos desarrollados a lo largo de la asignatura.

## Herramientas utilizadas
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
